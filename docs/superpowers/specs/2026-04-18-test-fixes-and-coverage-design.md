**File:** `tests/test_quality_gate_integration.py`

**Problem:** `enrich` mock returns `summary: "."` (1 char). `_gate_enriched_content` requires `prose_chars ≥ 300` from (summary + key_facts). Test fails at the prose gate.

**Fix:** Update the mock to return realistic prose content:

    "key_facts": [
        "First key fact with real content that contributes meaningful information.",
        "Second key fact expanding on the primary findings with additional details.",
        "Third key fact providing concluding analysis and broader context.",
    ],
    "cross_links": [], "entities": [], "figure_captions": [],
    "why_saved_hint": "", "raw_text": valid_content, "error": False,
}),

### Test 2: `test_pipeline_pdf_with_image_creates_note_and_saves_figures`

**File:** `tests/test_integration.py`

**Problem:** `fake_enrich` returns `summary: "A note generated by the integration test."` + tiny key_facts → prose=87, gate rejects it. The test was written before the prose gate existed (commit `9181c35`).

**Fix:** Update `fake_enrich` to return ≥300 prose chars from summary + key_facts:

```python
def fake_enrich(raw_text, similar_titles, source):
    substantial_summary = (
        "This integration test validates that PDF documents with embedded figures "
        "are correctly processed through the pipeline. The extraction captures both "
        "textual content and visual elements, preserving the document structure."
    )
    return {
        "title": "Integration Test Figure",
        "type": "paper",
        "tags": ["test", "integration"],
        "summary": substantial_summary,
        "key_facts": [
            "The PDF extraction process successfully captured the document content.",
            "Figure extraction generated PNG images from embedded visual elements.",
            "The note writer correctly replaced image placeholders with Obsidian links.",
        ],
        "cross_links": [],
        "raw_text": raw_text,
        "error": False,
    }
```
