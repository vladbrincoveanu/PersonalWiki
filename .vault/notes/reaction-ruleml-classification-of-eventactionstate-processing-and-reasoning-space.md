## Summary
This white paper presents Reaction RuleML, an XML-serialized language designed for reaction rules in event/action/state processing. It provides a comprehensive review and classification of reaction rule approaches and systems across multiple domains, establishing fundamental concepts for the event-action-state processing and reasoning space.

## Key Facts
- Reaction RuleML is a compact, user-friendly XML language for serializing reaction rules
- The paper reviews historical approaches to event/action/state processing and reaction rule systems in various application domains
- It provides a classification framework for event, action, and state processing reasoning techniques
- Authored by Adrian Paschke from Technical University Munich, published October 2006
- The work builds upon ECA-RuleML approach combining ECA rules with temporal interval-based knowledge representation
