Section 3 — Article Link Extraction for Drill-Down

When drilling, extract article links from the thin page. How to pick the best one?

Link Extraction Strategy
Link Filter Rules
  • ✅ Same domain as parent URL
  • ✅ Not a nav/header/footer link (heuristic: URL doesn't contain /nav/, /menu/, /footer/, /header/, /sidebar/)
  • ✅ Not already in _seen_urls or currently in-flight
  • ✅ URL looks like an article (has date, title slug, or /article/ /post/ /news/ / in path)
  • ❌ Skip pagination links (?page=2, /page/2/)
  • ❌ Skip media files (images, PDFs)
How to Pick the Best Link (Priority Order)
1st
Keyword in URL text or path — e.g., URL contains the search keyword
2nd
Longest URL slug — suggests a specific article title, not a category
3rd
First valid article link found in DOM order
Implementation: Extract links from Crawl4AI result
# After Crawl4AI returns markdown text:
def extract_article_links(html: str, parent_url: str, keyword: str) -> list[str]:
    from urllib.parse import urljoin, urlparse

    # Parse parent to get domain
    parsed = urlparse(parent_url)
    domain = parsed.netloc

    # Find all href links in HTML
    link_pattern = re.compile(r'href="([^"#]+)"')
    candidates = []
    for match in link_pattern.finditer(html):
        href = match.group(1)
        full_url = urljoin(parent_url, href)

        # Same domain?
        if urlparse(full_url).netloc != domain:
            continue
        # Skip nav/footer/pagination
        if any(x in full_url.lower() for x in SKIP_PATHS):
            continue
        # Skip media
        if any(full_url.lower().endswith(ext) for ext in MEDIA_EXTS):
            continue
        # Article-like?
        if any(indicator in full_url.lower() for indicator in ARTICLE_INDICATORS):
            candidates.append(full_url)

    return candidates[:5]  # top 5 candidates for scoring

Constants

SKIP_PATHS = [
    "/nav/", "/menu/", "/footer/",
    "/sidebar/", "/header/", "/pagination/",
    "/page/", "?page=", "/tag/"
]
MEDIA_EXTS = [".jpg", ".png", ".gif",
               ".pdf", ".mp4", ".zip"]
ARTICLE_INDICATORS = [
    "/article/", "/post/", "/news/",
    "/blog/", "/2024/", "/2025/",
    "/2026/"
]

Why this works

  • Same domain prevents linking to ads/trackers
  • Skip nav patterns removes listing/nav links
  • Article indicators catch most CMS article URLs
  • Keyword priority ensures we follow relevant content first
  • Max 5 candidates keeps scoring fast
