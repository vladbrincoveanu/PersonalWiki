Track A — Quality Gate (Decision Flow)

Every URL passes through 4 checks before enrichment. Reject early, fail fast.

Quality Gate: Implementation Notes

Check Method Fail Action
HTTP status HEAD request first (fast) Skip, log reason, don't retry same URL
Content length After extraction, count raw chars Skip if <500 chars (article), <200 words (video)
Paywall / auth Status 401/403 + content heuristics ("paywalled", "subscribe", "premium") Skip, add URL to suppression list
LLM relevance Lightweight MiniMax call: "Yes/No: does this content match the keyword '{keyword}'?" Skip, suppress keyword if 3+ failures for same keyword

Benefits

  • Garbage never hits the enrichment step (saves LLM cost)
  • Suppression list grows organically — system learns what you don't care about
  • Keyword scoring: if a keyword keeps producing off-topic content, it's demoted

Tradeoffs

  • Extra LLM call per URL (relevance check) — adds latency + cost
  • Can be bypassed for manual direct-injects (user knows best)
  • LLM relevance prompt needs tuning — may need a few-shot example
