Track B: Cycle Detection & Keyword Scoring

🔄 Cycle Detection

Amplification can loop — prevent it:

  • Track url→keyword lineage — if URL was already discovered via keyword X, don't re-suggest via keyword extracted from that URL
  • Depth limit: only amplify 1 level deep from original seed keywords
  • Decay: keywords extracted from notes degrade over discovery cycles if they keep producing off-topic results

📊 Keyword Scoring

Each keyword gets a quality score:

  • +1 per successful ingest from this keyword
  • -2 per Track A rejection
  • -5 if LLM says "off-topic" 3×
  • Suppress keyword if score < -5

Why this works

  • Graph naturally expands around your interests — a note on "transformers" begets notes on "attention", "BERT", "RLHF"
  • Quality gate ensures only good content amplifies — bad keywords die off
  • Score decay prevents stale keywords from polluting discovery

Risks

  • Echo chamber: too-narrow keywords reinforce each other → less diversity
  • Cycle detection adds state complexity
  • Need to tune amplification depth — too deep = noise, too shallow = no growth
