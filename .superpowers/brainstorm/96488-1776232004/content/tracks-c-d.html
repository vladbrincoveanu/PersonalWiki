⚡ Video Quality Gate

  • Transcript <200 words → reject (auto-captions too thin)
  • Channel blacklisted → reject
  • No transcript available after all 4 fallback tiers → store as stub note with video metadata only (no retry)

📊 Video Priority Scoring

  • Topic match: keyword overlap with user interests
  • Recency: newer videos weighted higher
  • Engagement: views/likes as secondary signal
  • Priority score = weighted sum; high-priority queued first

Track D benefits

  • Rerank fixes retrieval drift — vector match ≠ best answer match
  • Graph hops: if A mentions B and B mentions C, query on A returns A+B+C
  • Typed templates → LLM always knows where to find facts, summary, key quotes

Tradeoffs

  • Cross-encoder rerank adds latency (butordable for personal scale)
  • Typed templates require migration of existing notes
  • Graph hop retrieval needs graph data (wikilinks) — existing notes may lack them
