Key benefits

  • Bad content never enters vault (A)
  • Discovery amplifies itself — good notes → new keywords → better content (B)
  • YouTube isolated but shares core retrieval (C+D)
  • Type-specific storage → better LLM parseability (B+D)

Complexity note

  • Quality gate needs a scoring model (LLM or heuristic)
  • Amplification loop needs cycle detection to avoid loops
  • Video priority needs a scoring API (YouTube Data API or scrapes)
  • All four tracks share Track D — highest risk dependency
